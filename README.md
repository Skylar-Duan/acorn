# 橡果 Acorn 🌰

温暖纸感的 Windows 待办工具。把事情一颗颗收进来，一颗颗处理掉。

**记录零门槛**：随手一条「周五下午3点 提交周报 #工作 @李哥 !高」，日期、时间、清单、需求方、优先级全部自动识别。
**安排有章法**：今天 / 计划 / 日历拖拽改期 / 四象限定优先级。
**执行有陪伴**：番茄钟专注计时，迷你浮窗置顶陪跑。
**回头有交代**：完成热力图、需求方工作量分布、每周回顾一键导出 Markdown。

## 功能一览

- **随手记（统一记录入口）**：两种记法并排给——**打字**用中文自然语言（明天 / 周五 / 下周三 / 8月20日 / 十月底之前 / 每周一三五 / 下午3点…，配 `/清单`（不存在自动新建）`#标签` `@需求方` `!高`，全角半角与 `！！！` 都认，输入时自动补全已有项）；**不想背语法**就用下面一排按钮点着选日期 / 清单 / 需求方 / 重要性 / 重复，选中会一直生效，方便连记好几条
- **视图**：随手记 · 今天（逾期置顶）· 计划 · 全部（总览 + 排序切换：按时间/按重要性，排到子任务这一级）· 日志 · 日历 · 四象限 · 专注 · 统计
- **需求方维度**：每件事记录「为谁做」，侧栏按人聚合，统计页看各需求方工作量
- **任务**：备注、循环、到点系统通知提醒、顺延计数
- **子任务按「下一步」排**：一件事还剩几个子任务没做，列表里就占几行（「写周报 › 画趋势图」），母任务行先收起，全做完才回来收尾；子任务的日期与重要性**默认等于母任务**，也可以单独排期（拖到侧栏、右键推明天、任务卡里点日期，只动这一条）。今天 / 计划 / 全部三个视图口径一致
- **顺手**：任务行右键有完整菜单；任务可拖到侧栏（今天=改今天，计划=弹日期选择，清单/需求方=归属）；任务卡里输一句「明天 15点 !高」即可快捷修改
- **托盘常驻**：关窗进托盘；`Alt+Space` 全局唤起「随手记一条」小窗（可改键）
- **键盘流**：`Ctrl+K` 命令面板 · `Ctrl+F` 搜索 · `Ctrl+Z` 撤销 · `Ctrl+D` 完成 · `Ctrl+→` 推明天 · `Ctrl+1~5` 切视图
- **六款自然主题**：森林 / 海洋 / 星空 / 沙漠 / 雪山 / 南极，深浅双模式；每款自带一幅同色系的风景水印（针叶林 / 浪 / 银河 / 沙丘 / 冰川 / 极光），底纸与卡片带纸的颗粒
- **数据安全**：数据是一个人类可读的 JSON；原子写入 + 崩溃恢复；每日自动备份保留 30 份；回收站 30 天；导入导出 JSON/CSV/Markdown；版本升级自动无损迁移旧数据

## 数据存哪

默认在本机 `%APPDATA%\com.cdpandas.acorn\userdata\`，装完开箱即用。
设置页可把数据文件夹换到移动硬盘 / 网盘（换电脑打开是同一份任务；指针存 `%APPDATA%\com.cdpandas.acorn\config.json`，并记录用过的位置，数据本体不动）。

**不会让你以为数据丢了**：启动时如果数据文件夹是空的，橡果会先扫一遍数据可能待着的地方（默认目录、用过的目录、exe 旁边、被沙箱化的镜像目录），找到有内容的就列出来让你选——**你不点，它什么都不写**。选定的文件夹当下不可用时（硬盘没接等）会友好提示并可重试，不会闪退、不会悄悄新建空数据覆盖。

**导入导出**：导出的 JSON 带信封（`app` / `schema` / `appVersion` / `exportedAt` + 完整数据），老版本导出的裸数据也照样能导入；「导出→导入→再导出」逐字节一致，以后接服务器同步用的是同一份口径（`src/core/transfer.ts`）。

## 开发

```bash
npm install
npm run dev          # tauri dev（需要 Rust + VS C++ 工具链；Rust 若不在 PATH：$env:Path += ";$env:USERPROFILE\.cargo\bin"）
npm test             # vitest 单元测试（解析/循环/统计/搜索/store）
npm run build        # 打 NSIS 安装包 → src-tauri/target/release/bundle/nsis/
```

冒烟自检：`$env:ACORN_SMOKE="1"` 启动应用 → 自动跑「建任务→完成→落盘→重读校验」并写 `userdata/smoke-report.json` 后退出。

## 架构

```
src/
├─ core/            纯逻辑（全部可单测，零 DOM）
│  ├─ model.ts      数据模型唯一契约
│  ├─ dates.ts      日期工具（全应用统一 'YYYY-MM-DD' 本地语义）
│  ├─ parse.ts      快速添加的中文自然语言解析
│  ├─ recur.ts      循环任务下次日期引擎
│  ├─ stats.ts      统计聚合与每周回顾
│  ├─ search.ts     搜索排序
│  ├─ store.ts      zustand 状态中枢（唯一写入口 mutate：撤销栈 + 防抖落盘）
│  └─ persist.ts    存取桥（Tauri 命令 / 浏览器 localStorage 兜底）
├─ views/           今天 · 计划 · 通用列表 · 日历 · 四象限 · 专注 · 统计 · 设置
├─ components/      TaskRow · TaskCard · QuickAddBar · Sidebar · 命令面板 · 搜索
└─ windows/         快速添加浮窗 · 专注迷你浮窗（独立 webview，数据经主窗落库）
src-tauri/          Rust：原子写 + 崩溃恢复 + 每日备份轮换 + 托盘 + 单实例
```

关键设计：

- **数据只有主窗能写**。快速添加小窗解析后把结果发事件给主窗落库——三个 webview 各有内存，绝不两处写同一个文件。
- **原子写**：临时文件写入 → 读回校验 → 旧文件挪开 → 转正。任何一步崩溃，启动时都能从中间文件找回完整数据。
- **撤销**：所有用户写操作过 `mutate()` 进快照栈（50 步），删除另有回收站兜底 30 天。
