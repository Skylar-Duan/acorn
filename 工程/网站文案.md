2. **截图只用核对过的合成演示数据**，从根目录`界面截图/`选取并复制到`网站/assets/`。本批新Plus图需核对后才可公开；用户真实待办截图不能对外。
3. **安卓与网页入口继续暂停**：按钮灰色不可选，不留可点击的安卓备用下载；直接访问网页版显示“正在开发中”。
4. **以后每次发版我都会来 INBOX 留言**，格式固定：版本号 / 更新日志文案 / 截图路径 / 安卓上不上。链接不变，你只改文案。
5. **网页版（App 本体）从 v1.15.0 起由橡果自己发，不走 `publish_utility.py`。**
   2026-09-21 起地址调整：网页版挂根路径 `https://acorn.cdpandas.com/`（原 `/app/`，旧址 301 到根），
   介绍页挪到 `https://acorn.cdpandas.com/intro/`（10 管，acorn-site.inc 只管 `/intro`、`/intro/`、`/utilities/`）。
   网页版的 nginx 段（`/`、`/assets/`、`/icons/`、`/manifest.webmanifest`、`/app` 跳转）写在橡果仓库的
   `server/deploy/nginx-acorn.conf` 里，产物由橡果的 `publish-web.sh` 传到 `/var/www/acorn-web/`。

## 二、「它能做什么」

**section 标题**

```
它能做什么
```

**section 导语（一句，不要排比）**

```
下面这些是橡果每天真正在替你干的事。
```

### 卡片（按这个顺序，h3 是卡片标题）

**1 ｜ 一句话记一件事**

```
不用先选日期、再选清单、再点重要性。把话打完就行：

· 日期：明天 / 下周三 / 8月20日 / 十月底之前
· 时间与循环：下午3点、每周一三五
· /清单 · #标签 · @需求方 · !高

边打边显示解析出来的结果，不对当场改。
```

**2 ｜ 记得每件事是谁交办的**

```
橡果把「为谁做」当成和日期、清单同一级的东西。侧栏按人分栏，
点开某个人就是欠他的全部事情；统计里也各算各的。

如果你的事大多是别人交办的，按人看比按重要性排更管用。
```

**3 ｜ 习惯和待办分开算**

```
喝水、背单词、健身这类重复着做的事，有自己的一屏：
一个大圈点一下就是打卡，旁边是连续多少次和本周七格，点开能看整月日历。

习惯不会逾期。昨天没做就是没做，不会滚成一笔债堵在今天。
忘了打卡可以补，「每周一三五」这种也数得对——连续三次数的是该做的日子，不是自然日。
```

**4 ｜ 计划按「什么时候」分段**

```
今天 / 本周 / 本月 / 半年内 / 更远 / 未安排。不用在一条长列表里翻哪件是这周要交的；写「~半年内 考驾照」，日期就落在半年内那一段的最后一天。
换一个看法，就变成按重要性分成高 / 中 / 低 / 普通四段，每段里再按时间排。
```

**5 ｜ 先看整件事，再展开步骤**

```
电脑上的计划和今日任务先列母任务，点箭头展开待办步骤。子任务按日期、钟点排，同一时间再按重要性排。
母任务按自己与待办步骤中最近的日期排列。每一步默认显示一行，点箭头展开完整文字；长清单也可以收成前三条。
```

**6 ｜ 直接改标题，也能改安排**

```
电脑上直接在标题里写「~明天 !高」，日期和重要性会即时预览，确认后保存。子任务写「@李哥 /学习」，会在末尾追加归类小签，点×移除。
要保留符号本身，把内容放进双引号，例如「“@李哥 ~明天 !!!”」，引号里的内容只当正文。
```

**7 ｜ 账号与同步（可选）**

```
登录同一个账号，可以在不同Windows设备上继续处理任务。没网时照常使用，联网后再同步。网页版与手机版正在开发中。
设置中可选每5分钟、1小时、6小时或1天检查云端更新，本机修改仍会自动上传。同一件事两边都改过，以改得晚的那次为准。
退出登录保留本机数据；删除本地数据和注销橡果账号是单独的按钮，操作前都会确认范围。cdpandas统一账号保留。
```

**Plus ｜ 给任务附图**

```
在输入框里粘贴、拖入图片，也可以点子任务旁的小加号选图。收起时显示一枚缩略图，展开后完整文字和图片排在同一步里。
设置里的「图片空间」可逐张或多选删除，也能选择哪些图片同步到云端。云端图片空间为20 MB，本机不限制图片总量和张数。同一安装包，Plus资格随账号启用。
```

**8 ｜ 数据在你自己的机器上**

```
默认存在本机，装完就能用。想让数据跟着移动硬盘走，去设置里换个文件夹就行。

保存时先写好副本再替换，写到一半断电也不会碰坏原来那份；每天留一份备份共 30 份，
删掉的东西在回收站里放 30 天，日常的每一步操作都能撤销。

云端下载、删除本地数据和注销橡果账号前都会确认。这些动作不能用任务撤销恢复，下载替换账本前会留一份本机备份。
```

**9 ｜ 六款主题，各有一幅画**

```
森林的针叶林、海洋的浪、星空的银河、沙漠的落日沙丘、雪山的冰川、南极的极光，
淡淡地垫在任务下面。每款都有深浅两色。
```

**10 ｜ 键盘、右键、拖拽都通**

```
Ctrl+K 命令面板，Alt+Space 在任何地方叫出「记一条」小窗。
任务右键：完成、推明天、改日期、改重要性、移清单、换人、复制、删除。
拖到侧栏「今天」就是改今天，拖到某个人名下就是改需求方。
```

> 10 注意：**不要**在页面上出现「专注 / 番茄钟」——v1.9 起这个功能暂时收起了。
