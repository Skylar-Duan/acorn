## 二、「它能做什么」

**section 标题**

```
它能做什么
```

**section 导语（一句，不要排比）**

```
下面这些是橡果每天真正在替你干的事。
```

### 卡片（按这个顺序，h3 是卡片标题）

**1 ｜ 一句话记一件事**

```
不用先选日期、再选清单、再点重要性。把话打完就行：

· 日期：明天 / 下周三 / 8月20日 / 十月底之前
· 时间与循环：下午3点、每周一三五
· /清单 · #标签 · @需求方 · !高

边打边显示解析出来的结果，不对当场改。
```

**2 ｜ 记得每件事是谁交办的**

```
橡果把「为谁做」当成和日期、清单同一级的东西。侧栏按人分栏，
点开某个人就是欠他的全部事情；统计里也各算各的。

如果你的事大多是别人交办的，按人看比按重要性排更管用。
```

**3 ｜ 习惯和待办分开算**

```
喝水、背单词、健身这类重复着做的事，有自己的一屏：
一个大圈点一下就是打卡，旁边是连续多少次和本周七格，点开能看整月日历。

习惯不会逾期。昨天没做就是没做，不会滚成一笔债堵在今天。
忘了打卡可以补，「每周一三五」这种也数得对——连续三次数的是该做的日子，不是自然日。
```

**4 ｜ 计划按「还有多久」分段**

```
一周内 / 一个月内 / 半年内 / 更远。不用在一条长列表里翻哪件是这周要交的。
换一个看法，就变成按重要性分成高 / 中 / 低 / 普通四段，每段里再按时间排。
```

**5 ｜ 有子任务的事，按「下一步干什么」排**

```
一件事还剩几个子任务没做，列表里就占几行（「写周报 › 画趋势图」），
母任务先收起来，全做完了它才回来收尾。

子任务没单独填日期和重要性时就等于母任务的：母任务定在周五，
它的子任务周五当天自己出现在「今天」。
```

**6 ｜ 改一整句话，就是改这件事**

```
点开任何一件事，底下那栏已经写好了它的完整一句话。
删掉「!高」就降级，删掉「@李哥」就把人摘了，旁边一个按钮随时还原。
```

**7 ｜ 电脑和手机同一份事**

```
一个邮箱就能跨设备。新装的设备登录后直接拿到云端那份；这台设备上已经记了事的话，
登录时会问你是把两边合起来还是用云端那份。同一件事两边都改过，以改得晚的那次为准。

断网、服务器出问题都不影响你继续用，本机那份照常读写。
不注册的话跟以前完全一样，一个字都不会往外传。

登录之后，退出登录会把这台设备上的数据一起清掉，只留云端那一份——
清之前橡果会先跟服务器对一次账，没对上就一条都不清。
```

**8 ｜ 数据在你自己的机器上**

```
默认存在本机，装完就能用。想让数据跟着移动硬盘走，去设置里换个文件夹就行。

保存时先写好副本再替换，写到一半断电也不会碰坏原来那份；每天留一份备份共 30 份，
删掉的东西在回收站里放 30 天，日常的每一步操作都能撤销。

唯一不能撤销的是设置里那两个明确写着「会覆盖 / 会清空」的动作，点之前会让你确认。
```

**9 ｜ 六款主题，各有一幅画**

```
森林的针叶林、海洋的浪、星空的银河、沙漠的落日沙丘、雪山的冰川、南极的极光，
淡淡地垫在任务下面。每款都有深浅两色。
```

**10 ｜ 键盘、右键、拖拽都通**

```
Ctrl+K 命令面板，Alt+Space 在任何地方叫出随手记。
任务右键：完成、推明天、改日期、改重要性、移清单、换人、复制、删除。
拖到侧栏「今天」就是改今天，拖到某个人名下就是改需求方。
```

> 10 注意：**不要**在页面上出现「专注 / 番茄钟」——v1.9 起这个功能暂时收起了。
> 现在页面上「九个视图」那张卡里写了「专注」，要改掉。

## 三、更新日志区（releases）

写法纪律：**一版一句话概括 + 三到六条要点，每条一句**。
Bug 修复统一写成「修复 XX」，不讲根因；看不见的内部优化不写进来。

```
v1.11.1
  手机版第一轮试用后的修整。
  · 登录时如果云端和这台设备上都有东西，两份档案并排给你看，选一份用，或者合并（重复的只留一份）
  · 手机上每一页都有了顶栏；底部导航改为 今天 / 习惯 / 计划 / 已完成 / 更多
  · 子任务按日期自动排，没填日期的排在后面
  · 登录页换上橡果图标；另有一些细节调整

v1.11.0
  手机版从头做了一遍。
  · 一件事一行，右滑完成，左滑推明天 / 放弃 / 删除，长按弹出常用操作
  · 点一件事从底下拉出详情，改日期、清单、需求方都在同一张纸上
  · 记一条全靠点：打完事情本身，日期、清单、需求方、重要性点一下就选好
  · 第一次打开会问要不要登录，不登录也能用；电脑上是同一套登录页
  · 标题换文楷，正文换思源黑体，手机和电脑一样

v1.10.1
  手机版跟上来了，更新也不用再去网页找。
  · 安卓版追到了和电脑一样的版本，登录同一个账号，两边看到的是同一份
  · 打开橡果会自己查有没有新版，查到就地下载安装；更新日志顶上也能手动查
  · 在任务卡里连着加子任务，卡片会停在原地，收起后再归位
  · 更新日志换了新样子；设置页去掉了重复的回收站入口

v1.9.1
  计划页能搜了，日历有了周视图。
  · 计划页标题下多了搜索框，标题、子任务、备注、标签、需求方都搜得到
  · 日历可以切到按周看
  · 设置页每一节都能收起展开，收起时留一句摘要
  · 「橡果」旁边多了版本号，点开就是更新日志
  · 另一台设备先升级了也不要紧，这台照常打开、照常用

v1.9.0
  一件事可以放弃了，安排日期也更快。
  · 做完之外多了「放弃」：收进「已完成」里的「放弃的」一栏，随时能放回来
  · 安排日期的快捷预设换成 今天 / 本周五 / 本周日 / 本月末，过了的自动往后推
  · 在任何输入框里打完字，点到别处就算存下；撤销一次撤的是刚才那件事
  · 「已完成」按子任务列，做完的事也落到日历上真正做完的那一天，日历顶上可以筛
  · 每天自动跟云端对一次账；新增「从云端覆盖到这台设备」；退出登录会把这台设备上的数据一起清掉，清之前先对账

  · 「全部」改叫计划，接下来分成 一周内 / 一个月内 / 半年内 / 更远
  · 「日志」改叫已完成，挪到侧栏一眼看得见的位置

  · 子任务链可以收起来，只留「下一步」那条
  · 任务卡里改一整句话就是改这件事
  · 勾掉一件事会告诉你它去哪了，并且能直接撤销
```
