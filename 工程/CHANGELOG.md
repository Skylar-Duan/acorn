- **应用内更新第一次真跑就挂了的两处**（用户 2026-09-02 报：「Failed to fetch」+「改用浏览器下载」没反应）：
  - **服务器**：`/download/` 是 nginx 静态目录，没有 CORS 头；橡果在 webview 里（`tauri.localhost` 源）用 `fetch` 拉包，
    跨源响应缺 `Access-Control-Allow-Origin` 直接被内核拒收，界面只剩一句「Failed to fetch」。`/api/` 那边是 FastAPI 的
    CORS 中间件在给，静态目录得 nginx 自己给。补了 Allow-Origin `*`、Expose-Headers（进度条要 Content-Length 当分母）、
    OPTIONS 预检回 204。**这一条改的是服务器，用户手里的 v1.9.1 点「重试」就好了**，用 Playwright 从别的源 fetch 过三个地址确认。
    以前从没人真跑过这条路（安卓真机一直没验），所以拖到现在才炸。
  - **客户端**：capabilities 只给了 `opener:allow-open-url` / `allow-open-path` 这两条**命令**权限，没给 URL / 路径**范围**，
    插件一律拒绝；`openFallback` 兜底的 `window.open` 在 Tauri 的 webview 里静默无效——按钮就成了「按了什么都不发生」。
    现在 `opener:default`（自带 http/https 默认范围）+ 显式放行 `acorn.cdpandas.com` / `github.com` + `open-path` 放行 `$APPCACHE/**`
    （安卓装 APK 靠 `openPath` 打开 `write_to_cache` 存下的文件，同一个病，只是还没人撞上）。
    `openFallback` 改开**安装包直链**（不是 Release 页——Release 没发时那页是旧版本），三种结果都回给界面：
    开了 / 打不开就把地址复制到剪贴板 / 连剪贴板都不行就把地址原文显示出来。`tests/opener-scope.test.ts` 钉住 capabilities、
    updater、两个入口和 nginx 配置四处。

## v1.9.1 · 2026-09-01

- **橡果再也不会因为「这份数据太新」就不给你看自己的日志**。以前一台电脑升级了、另一台还没，
  没升的那台打开橡果只有一屏「版本过旧」，一条任务都进不来，同步也永久停摆，
  重启都解不开（得重新登录一次才行）。现在：**照常打开、照常记、照常改、照常同步**，
  弹一次「已有更新版橡果」的框——新版本支持更多功能，建议更新后再继续编辑；
  下面「现在更新 / 取消」两个键，**取消了照常用**（万一没网又急着用）。
  每次打开都会再问一次（它带着「现在更新」这条行动，不该关一次就永远不提），点了取消这次不再弹。
  文案与形态是用户 2026-09-01 定的：不做常驻横幅，也不做「关掉就永远不提」。

- **计划里可以搜索了**。标题下面一条搜索框，标题 / 子任务 / 备注 / 标签 / 需求方任一命中就留下，
  一件事留下就连它的所有行一起留下。Ctrl+F 在这个视图里直接聚焦它（别处照旧弹全局搜索）。
  跟全局搜索浮层的两处不一样：不截断（浮层只显示前 50 条，当筛选器用会静默丢事）、
  只认子串不认子序列（「ab」不再把任何含 a…b 的标题都留下）；子任务标题也搜得到——
  计划视图本来就是按子任务分行的，那一行明明在屏幕上、搜它的名字却一无所获，用户会当成坏了。

- **日历新增周视图**，在月历翻页按钮左边切换。只是「一行七格、格子更高」，不带时间轴。
  周视图一格能列 10 条（月视图 3 条），七天全亮不压暗；标题写成「9月1日 – 9月7日」，
  跨年或不是今年才带年份。切换时锚点会归一（周视图是周一、月视图是月首），
  否则拿周一去算月网格会整片错位且不报错。

- **设置页分节可以收起展开**。标题行整条可点，右边一个小三角；收起时标题旁给一句摘要
  （比如数据那节显示数据文件夹在哪、行为那节显示现在的全局快捷键），不点开也知道里面是什么。
  默认「外观」「云账号」打开、其余收起，开合记在本机。
  正文用高度收不下树——条件渲染会把数据节的备份列表、行为节里打了一半的快捷键清掉。
  侧栏同步指示点一下滚到「云账号」时会先把那一节打开。

- **「橡果」旁边有了版本号**，点它就是给使用者看的更新日志（设置页「关于」那张卡上也有同一个入口）。
  设置齿轮往右挪了 4px，跟下面侧栏那些计数数字的右缘对齐（用户点名的）。

- **每一行右边只留日期，长标题不再把日期挤出去**。病根一处：`.row-slot > .task-row` 少了 `min-width:0`，
  标题那条 ellipsis 规则一直是对的，只是从来没机会生效。行尾的清单色点 / 需求方徽标 / #标签
  全局收起（`tail` 开关默认 lean，`full` 那条退路留着），重要性小旗和「已放弃」灰标签留着。
  已完成页 `tail=date`：只画「完成于 / 放弃于 X」，截止日、进度、循环、顺延全收；
  日期格定宽 88px **左对齐**（对齐的是起笔），超一年那档单独放宽、写两位年（`formatDoneShort`，
  跟 `formatShort` 分家，后者 8 处调用一个字没动）。点开走 CardSlot，行和卡同时挂着、都有动画。
  标题 / 子任务名 / 整句改三个框换成自动撑高的 textarea（`autogrow.ts`），
  Enter→备注 / Shift+Enter→收卡 那套约定原样保住，粘贴进来的换行当空格吃掉。
  顺带修掉：顺延徽标漏到已放弃行（判据改成「未了结」不是「未完成」）。

- **子任务收起后不再多出一截空白，能点的地方多了**。一个 CSS 病根解释了三件事：
  `.row-slot.shut` 的 0fr 收不到 0，因为 `.task-row` 自己有 padding（盒子不可能比 padding 矮）——
  每行残留 16px、卡片位残留 42px，「收起子任务」总开关一按整页一截一截空白。
  现在 padding 一起压掉并纳入过渡，`@keyframes row-leave` 关键帧同步。
  折叠热区：小三角 24×24、「母任务 ›」前缀可点、「+N」可点、←/→ 键收放。

- **看不见的东西，一个字都不会被吃掉**。这是上一条的前提，也是这一版真正的重活：
  以前老版本读一遍新数据再存回去，会**悄悄**吃掉三样东西——新版本新增的整块内容、
  删除记录上的新字段、以及「这份数据本来是第几版」这个事实本身。
  每同步一次、每彻底删一次就再吃一层，用户毫不知情。现在这三处都堵上了，
  改一条任务、跟另一台设备合并、导入导出走一圈，看不见的部分原样躺在那儿等你升级。

- **同步停摆不再是死局**。被服务器挡回来时它只是**暂停**：过几小时自己再试一次，
  重开一次橡果也会重试。侧栏那行字也从「同步已停，需升级」改成「同步暂停，升级后恢复」——
  前一句读着像判了死刑，其实升完级它自己就回来了。

- **数据格式没动**（仍是 schema 6）。这一版改的是「怎么读、怎么存回去」，没有新增任何字段，
  所以不会把任何设备踢出同步。

## v1.9.0 · 2026-09-01

> ⚠️ **这一版换了数据格式（升到 schema 6，一次装下「子任务完成时刻」和「放弃」两处改动）**。装上它并同步一次之后，
> 手机上那份旧 APK 会停止同步，提示「需要升级」——要等出一版新的手机端才能恢复。
> 电脑上的数据不受影响；手机上本来也没有电脑这边没有的东西。

- **打字这件事从头理了一遍：点走 = 存下，只有 Esc 才丢弃**。以前橡果里能打字的地方有十来处，
  规矩互相打架：侧栏新建清单、日历格里补记是**点走就白打**；清单改名、设置里的快捷键是自动存；
  任务卡里的需求方、标签、新子任务、整句改则悬在那儿不存也不丢。现在全应用一个规矩：
  - **点到别处 = 存下**。侧栏新建清单和日历格补记按「**空的就丢、有字就存**」办
  - **Esc 才是丢弃**。在哪个框里按就只丢那个框里的字，不会顺手把整张卡收了
  - 回车之后**框留在原地清空**，可以接着建下一张清单 / 下一条当天的事

- **存上了会告诉你一声**。以前打字类操作一句反馈都没有——存没存上全靠猜。
  现在提交那一下**输入框边框亮一下（0.2 秒），右边浮出一个「✓」，停 0.8 秒淡出**。
  任务标题、备注、子任务名、习惯名这几处本来就是边打边存的，**停手半秒**也会闪一下。
  不加确认按钮，也不用底部那条黑色提示——那条是留给「删了还能撤回来」用的

- **`Ctrl+Z` 撤的是「刚才那件事」，不再是「刚才那个字」**。以前标题打 20 个字就往撤销栈里
  塞 20 份快照，之前删掉的东西转眼就被挤没了。现在**同一个框里连着打的字合并成一份**
  （停手 0.8 秒才另起一份），撤销栈上限也从 50 降到 10 —— 能撤回去的事反而更多。
  两件事各改各的、同一件事的标题和备注，永远不会并成一份。
  **落盘照旧一个字都不少**：改的只是撤销的颗粒度，绝不会丢字

- **清单名改成了正经的输入框**。以前那是个「看不出能改」的大标题，回车不但不生效还会插一个换行，
  也没法反悔。现在鼠标移上去会露一圈淡边框，回车 / 点走都是存，**Esc 还原**，清空则还原显示

- **一张任务卡可以一路回车敲完**：标题上回车**跳到备注**（不再是收卡片），子任务那一栏回车
  接着建下一条，想收卡片按 **Shift+回车**。「整句改」那栏打到一半按 Esc 分两级：
  第一下只把这句**还原**，第二下才收卡片——手一抖不至于前功尽弃

- **界面不再一惊一乍**：点开一件事、收起一件事、勾掉一件事、换个视图、开合侧栏，
  东西都是长出来、收回去的，不再是啪一下换一张图。
  觉得动得多了想调轻或者干脆关掉，改 `src/styles/base.css` 里 `--dur-1` / `--dur-2` 两个值就行；
  系统里开了「减少动态效果」的，橡果自己会降下来（包括跳到「云账号」那一下的平滑滚动）。
  **换主题仍然是瞬间齐切，没做颜色渐变**：只渐几块大面的底色、字的颜色还是瞬切的话，
  浅↔深切换的中段会出现浅字压浅底，任务卡标题几乎看不见——半做比不做难看，所以这条撤回了。
  要做完整版，得把几十处显式写死前景色的地方一并纳入同长过渡。
  **「收起 / 展开子任务」那个总开关走硬切**（一次翻掉上百行，做高度动画正好在行最多时最卡），
  单条小三角照旧有收放动画

- **一件事除了做完，还可以「放弃」**。有些事就是不做了，但它没做成——以前只能勾掉（假装做完，
  完成率跟着虚高）或者删掉（连痕迹一起没了）。现在它有自己的去处：
  - **圆圈一点没动**，还是只管完成。放弃是标题旁边一个灰色小标签「已放弃」，标题划一道
  - 三个地方能标：任务卡右下角那个「⊘ 放弃」（跟 🗑 站一块儿，都是「按下去这行就不在了」的键）、
    右键菜单里的「放弃 / 取消放弃」、子任务行上的小按钮。**子任务也能单独放弃**
  - 标了之后它**跟做完的事一个待遇**：从所有待办视图里退出（今天 / 计划 / 四象限 / 日历 /
    随手记 / 清单 / 需求方 / 标签），侧栏和统计页上「还欠几件」的数字也都不再算它，
    收进**「已完成」**——那儿顶上新加了
    「**做完的 / 放弃的 / 全部**」三选一，默认「做完的」，选了会记住。**侧栏没多出新条目**
  - **随时反悔**：取消放弃就回到未完成。这一下也进撤销栈，`Ctrl+Z` 照样撤得回来
  - **统计里单独算一档**，一件都不并进完成数——不然完成率虚高，那个数字就废了。
    周报里多一节「本周放弃」，一件都没有时整节不出现
  - **循环任务放弃 = 这一轮不做了，下一轮照常来**（跟完成同一套推进逻辑）。
    想彻底不做，请用删除
  - 一件事不会既做完又放弃：勾完成会自动撤掉放弃标记，反过来也一样

- **「安排日期」的快捷预设换成了「今天 / 本周五 / 本周日 / 本月末」**，去掉「明天」。
  **凡是「安排日期」的地方全都换了**：任务卡上的日期弹层、子任务的日期小签、
  右键菜单里的「安排日期 ▸」（任务的和子任务的）、把任务拖到侧栏「计划」弹出的「安排到哪天？」——
  五处同一套预设，一处算一处用。几个讲究：
  - 算出来的日子**永远向后取最近的那一个**，过了就顺延到下一个，名字跟着变——
    周六点开时「本周五」会显示成「下周五」。周从周一算起
  - **跟「今天」是同一天的那个预设直接不显示**（比如周五点开就没有「本周五」），
    省得两个按钮干同一件事
  - `Ctrl+→` 推明天、逾期区那个「全部推到明天」**都没动**——那是顺延，不是安排日期

- **日期弹层不用再点「确定」了**。以前它有两套规矩：点「今天」立刻生效，自己选日期时间却要
  再点一下「✓ 确定」，不点就白填。现在只有一套：**点预设 = 设好并关掉；点日历里的某天 =
  立刻生效但弹层留着**（好接着设时间）；**时间点完鼠标一移开就生效**。
  那个「确定」按钮删掉了。翻月仍然只是翻着看，不会顺手把日期改了

- **「已完成」现在按子任务列**：一件事分几步做完，就在这儿占几行（「装修 › 量尺寸」），
  母任务勾掉了另占一行表示这件事收尾了。以前只有整件事做完才冒出来一条，
  中间那些「今天把这一步做完了」的记录一条都看不见。
  从现在起，**勾掉一条子任务会记下是哪天勾的**。这个字段之前就已经勾掉的老子任务没有日期，
  分两种处理：母任务也已经完成的，跟着母任务的完成日走；母任务还没完成的，
  **它到底哪天做完的没人知道**——这类条目照样列在「已完成」里（沉在最后一组的末尾），
  但**不写完成日期、也不进日历**。宁可不说，也不给它编一个日子

- **做完的事也进日历了**，落在**真正做完那天**——拖了三天才补上的事，落在补上的那天，
  不是原来那个截止日。日历头上多了「全部 / 计划 / 已完成」三选一，选了会记住。
  做完的那条画成划掉的浅色，也拖不动（拖一件做完的事去改截止日没有意义）。
  日格右上角那枚绿点数字照旧，还是「这天干成了几件」（同一件事的几条子任务同一天勾完只算一件）。
  一格放不下的会在日期右边标「+N」

- **数据文件比这台上的橡果新时，不再硬读**：会明说「这台设备上的橡果太老了」，
  并且**一个字都不写回磁盘**。以前这条路是静默降级读进来，用户随手改一下就把降级后的数据
  盖回去了——数据目录放在两台机器共用的移动硬盘上时真会遇到

> 注：侧栏和「今天」上的「完成 N/total」、统计页仍然按**件**算（一件事只算一次），
> 「已完成」页顶上的数字按**条**算（子任务各算一条），两个数对不上是正常的，不是漏算。

- **任务卡里做完的子任务会自己收起来**：攒到 3 条就折成一行「显示已完成 N」，点一下摊开、再点收回。
  一件事的子任务全做完时不收（不然在「已完成」里点开卡片一条都看不见）。
  另外「＋子任务」那一栏挪到了已完成上面——以前它压在一堆划线的字底下，加一条得先滚半天

- **专注（番茄钟）暂时收起了**，侧栏、右键菜单、任务卡上都不再出现；以前记下的专注时长没丢。
  设置的齿轮从侧栏左下角挪到了「橡果」这一行的右边

- **手机上也能给清单和需求方换顺序了**：按住某一行不放，它会浮起来，这时候拖到别处松手就换位置。
  v1.8.0 加的「拖着换顺序」在手机上其实用不了——手指拖动不触发拖拽，看着像坏了

- ⚠️ **登录过账号的话，「退出登录」现在会连这台机器上的数据一起清掉**。
  这跟 v1.5.0 那句「退出登录（本机数据一条不动）」不一样了，是有意改的：
  登了账号，数据的家就在云端，退出登录 = 这台机器上不留痕迹。
  几条一定要知道的：
  - **清之前会先当场同步一次，同步不成功（断网 / 登录过期 / 版本太老）就一条都不清**，
    并且给你一个「先导出一份 JSON 再说」的出口
  - **「只退出登录，保留本机」一直摆在旁边**，不是只在出错时才冒出来：想换个账号登、
    或者只是暂时不同步了，用它，这台设备上的东西一条不动
  - **清空会连你以前换过的那个数据文件夹里留下的旧账本一起清掉**。以前只清当前那个文件夹，
    清完一重启，「找到了你以前的数据」又把旧的那份端回来，等于白清
  - **清空之后那一次打开是干干净净的空白**，不会先给你造两条「工作」「生活」；
    重新登录，云端那份会把内容填回来
  - **每天自动存的那 30 份备份只在本机、云端没有**，清掉就是 30 天历史永久消失。确认框里会点名说这件事
  - **「注销账号」正好相反，本机那份一个字都不动**。云端连备份一起删干净之后，
    本机这一份就是你唯一剩下的了，提示里会讲清楚
  - **登录状态过期被踢下线（非自愿登出）不会清任何东西**——那个时刻恰恰同步不上去
  - 从没登录过账号的人完全不受影响：这条路对你不存在，界面上没有、底层也会拒绝

- **卸载橡果时不再留下令牌和浏览痕迹**：卸载会删掉登录令牌和 WebView 缓存。
  这两样都不是你的内容，删了一条待办都不会少。
  **你的任务数据，卸载时橡果一个字都不动**——删不删只跟卸载向导里那个
  「删除应用程序数据」勾选框走（默认不勾），你换到别的盘的那个数据文件夹更是碰都不碰：
  那是你自己挑的文件夹，里面可能还放着别的东西，不该由卸载程序替你做主。
  ⚠️ **想要「删掉软件、本机不留」，顺序是：先在软件里点「退出登录并清空本机」，再卸载。**
  只有软件里那条路有闸门——它会先同步一次，确认东西都在云端了才清；
  卸载程序判断不了你有没有改动还没传上去

- **安卓版关掉了系统自动备份**（`allowBackup=false`）。以前 data.json 和登录令牌会被
  Android 自动备份传到你的 Google 账号、换机时再复制过去，那样「卸载不留」只对这台手机成立。
  代价：换手机不能靠系统迁移带走橡果的数据了，用云账号登回来就是

- **新增「从云端覆盖到这台设备」**（设置 → 云账号，登录后可见）。
  换了新机器、这台上的数据清过或者对不上时，用它把云端那份**整份**取回来。
  这是单向覆盖不是合并——这台机器上有、云端没有的事会消失，所以覆盖前会自动在
  数据文件夹的 `backups` 里留一份 `pre-restore-*.json`，确认框里会告诉你在哪，
  覆盖完成的提示里也会写清这份退路叫什么名字。
  **这份备份是硬条件**：磁盘满了、文件夹写不进去导致备份没存成，就直接停下不覆盖，
  本机一个字节都不改。云端还没有数据、或者拉不下来时，同样一个字都不动

- **每天至少自动同步一次**：以前只有「本地改了东西」才会往云上传，一台设备光看不改就可能
  永远拉不到另一台的更新（桌面版常驻托盘还会好几天不重启）。现在应用回到眼前时，
  如果当天还没成功同步过就自己补一轮。没打开过软件当然不算，橡果不会为此在后台守着或定时唤醒；
  没网就悄悄跳过，不弹任何东西

- **电脑上也能自己更新了，而且每次打开就自己查一次**（手机上一直有，现在两边一样）。
  查到新版会弹个框，告诉你新版本号、包多大、这一版改了什么，你可以当场「下载并安装」，
  也可以「稍后再说」，或者「这一版不再提醒」（只记这一个版本号，下一版照样问你）。
  电脑上点了安装之后，橡果会先把没存的东西落盘、再自己退出，把位置让给安装程序——
  不退出的话新版根本装不进来，装完它会自己重新打开。
  几件让路的事：正在问你「找到了你以前的数据」时不弹更新框，「这台设备上的橡果太老了」也排在前面

- **没网的时候不再骗你说「已经是最新版了」**。查不到就明说「版本更新检测失败，请检查网络连接」，
  是屏幕下方一条几秒就散的小消息，不拦任何操作；查更新最多等 12 秒，超时自己断掉，
  绝不会把启动卡住

- **「用法」不再是一个页面，改成一个单独的窗口**。侧栏「更多」里那一项和命令面板里那条都撤掉了。
  记新计划时点「随手记」右边的 `?`，或者到设置 → 一句话记事 → 打开用法，开的是同一个窗口，
  可以一边看例子一边接着记。关掉只是收起来，下次点开还是它。手机上没有第二个窗口，
  点开的是应用内的全屏说明

- **全局文案过了一遍**：说明、提示、空状态和按钮上的话都改成直说这东西干什么，
  去掉了给软件安动作的说法和排比句。空状态里、以及每周回顾导出的 Markdown 标题里那些
  纯装饰的表情符号删掉了（优先级旗、清单色点这类有含义的照旧）。
  云账号那几处本该是粗体、却把 `**` 原样显示给人看的地方也一并修好

## v1.5.0 · 2026-08-21

橡果有账号了：手机和电脑上看到的可以是同一份事。

- **注册一个账号，多台设备同一份任务**。设置页「云账号」里用邮箱注册（会收到一封验证码确认是你本人），登录之后这台机器上的事自动传到云端，别的设备登同一个账号就看得到
- **登录不会覆盖你已有的事**：本机那份和云端那份是**合起来**的，两边各记各的都在；同一件事两边都改过，以改得晚的那次为准
- 同步是自动的：记完东西过几秒自己传，关窗前再传一次。断网、服务器抽风都不影响你继续用——**本机永远能用，数据永远在本机也留着一份**
- 忘记密码可以用邮箱找回；不想用了可以退出登录（本机数据一条不动）或注销账号（云端那份连备份一起删干净）

> 📌 上面这两条是 v1.5.0 当时的说法，**v1.9.0 改了口径**：登录过账号之后，「退出登录」会连
> 这台机器上的数据一起清掉（清之前必须同步成功，否则一条不清）；「本机永远留着一份」只在
> 没登录账号时成立。「注销账号」仍然一个字都不动本机。详见最上面那一节。
- 不登录的话跟以前完全一样，什么都没变
