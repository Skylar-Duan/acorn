橡果 Acorn

多数待办工具都假设事情是你自己给自己安排的。橡果不是——它记得每件事是谁交办的，侧栏按人分栏，一眼看清欠了哪位同事几件事。

打一句话进去：

~周五下午3点 提交周报 /工作 @李哥 !高

日期、时间、清单、需求方、重要性，五样一次到位，不用先选再选。
不想记这套写法，输入框下面就是一排按钮，点着选一样。

当前版本 v1.17.1 · Windows桌面 · 数据存在你自己的机器上

目前优先提供Windows桌面版。网页版、手机版正在开发中。Windows使用同一安装包，Plus账号登录后自动启用附图功能。

它能做什么

下面这些是橡果每天真正在替你干的事。

一句话记一件事

不用先选日期、再选清单、再点重要性。把话打完就行：

  • 日期：~明天 / ~下周三 / ~8月20日
  • 时间与循环：~下午3点、~每周一三五
  • /清单 · #标签 · @需求方 · !高

边打边显示解析出来的结果，不对当场改。

记得每件事是谁交办的 需求方

橡果把「为谁做」当成和日期、清单同一级的东西。侧栏按人分栏，点开某个人就是欠他的全部事情；统计里也各算各的。

如果你的事大多是别人交办的，按人看比按重要性排更管用。

习惯和待办分开算

喝水、背单词、健身这类重复着做的事，有自己的一屏：一个大圈点一下就是打卡，旁边是连续多少次和本周七格，点开能看整月日历。

习惯不会逾期。昨天没做就是没做，不会滚成一笔债堵在今天。忘了打卡可以补，「每周一三五」这种也数得对——连续三次数的是该做的日子，不是自然日。

计划按「什么时候」分段

今天 / 本周 / 本月 / 半年内 / 更远 / 未安排。不用在一条长列表里翻哪件是这周要交的；写「~半年内 考驾照」，日期就落在半年内那一段的最后一天。

换一个看法，就变成按重要性分成高 / 中 / 低 / 普通四段，每段里再按时间排。

先看整件事，再展开步骤

电脑上的计划和今日任务先列母任务，点箭头展开待办步骤。子任务按日期、钟点排，同一时间再按重要性排。

母任务按自己与待办步骤中最近的日期排列。每一步默认显示一行，点箭头展开完整文字；长清单也可以收成前三条。

直接改标题，也能改安排

电脑上直接在标题里写「~明天 !高」，日期和重要性会即时预览，确认后保存。子任务写「@李哥 /学习」，会在末尾追加归类小签，点×移除。

要保留符号本身，把内容放进双引号，例如「“@李哥 ~明天 !!!”」，引号里的内容只当正文。

Plus，给任务附图

在输入框里粘贴、拖入图片，也可以点子任务旁的小加号选图。收起时显示一枚缩略图，展开后完整文字和图片排在同一步里。

设置里的「图片空间」可逐张或多选删除，也能选择哪些图片同步到云端。云端图片空间为20 MB，本机不限制图片总量和张数。同一安装包，Plus资格随账号启用。

四象限，看任务的位置

重要性越高越靠上，截止越近越靠右，近期日期拉开、远期压缩。有待办步骤时只显示可执行的子任务点。

拖动点时跟随预览日期和重要性，松手保存；左键按住时点一下右键取消。

账号与同步 可选

登录同一个账号，可以在不同Windows设备上继续处理任务。没网时照常使用，联网后再同步。网页版与手机版正在开发中。

设置中可选每5分钟、1小时、6小时或1天检查云端更新，本机修改仍会自动上传。同一件事两边都改过，以改得晚的那次为准。

退出登录保留本机数据；删除本地数据和注销橡果账号是单独的按钮，操作前都会确认范围。cdpandas统一账号保留。

数据在你自己的机器上

默认存在本机，装完就能用。想让数据跟着移动硬盘走，去设置里换个文件夹就行。

保存时先写好副本再替换，写到一半断电也不会碰坏原来那份；每天留一份备份共 30 份，删掉的东西在回收站里放 30 天，日常的每一步操作都能撤销。

云端下载、删除本地数据和注销橡果账号前都会确认。这些动作不能用任务撤销恢复，下载替换账本前会留一份本机备份。

六款主题，各有一幅画

森林的针叶林、海洋的浪、星空的银河、沙漠的落日沙丘、雪山的冰川、南极的极光，淡淡地垫在任务下面。每款都有深浅两色。

键盘、右键、拖拽都通

CtrlK 命令面板，AltSpace 在任何地方叫出「记一条」小窗。

任务右键：完成、推明天、改日期、改重要性、移清单、换人、复制、删除。

拖到侧栏「今天」就是改今天，拖到某个人名下就是改需求方。

怎么打这一句

随便打，认得出来的部分会变成对应的字段，剩下的就是任务标题。不想记这套写法，输入框下面就是一排按钮。

你打的它记下的
~明天 / ~下周三 / ~8月20日 / ~十月底之前到期日
~下午3点 / ~晚上八点具体时间，到点弹系统通知
~每天 / ~每周一三五 / ~每月10号循环，做完自动生成下一次
/工作归到「工作」清单，新清单先确认名称与外观
#汇报打上「汇报」标签
@李哥需求方是李哥，一件事可以挂好几个人
!高 / ！！！重要性（全角半角都认）
"@李哥 ~明天 !!!"双引号内按正文保留，半角、中文和全角双引号都支持

一整句长这样

~周五下午3点 提交周报 /工作 #汇报 @李哥 !高

输入时已有的清单、标签、需求方会自动补全，不用怕打错名字建出重复的一份。

安装须知

点上面的「下载」，挑 Windows 版，双击安装即可，装完开箱即用。

  • Windows 10 / 11（64 位）；按用户安装，不需要管理员权限
  • 装完会自己检查更新：打开橡果会查有没有新版，查到就地下载安装
  • 用系统自带的 WebView2 渲染界面，Win11 出厂即有；Win10 若缺会提示装一次
  • 没买代码签名证书，Windows SmartScreen 会提示「未知发布者」→ 点更多信息 → 仍要运行（仅首次）
  • 任务默认存在本机的应用数据区；想让数据随移动硬盘走，去设置 → 更换文件夹
